Fact sheet

The essentials, ready to quote.

What
Open-source software for building federated, community-governed digital spaces
Started
2021
Latest release
Bonfire 1.1 (November 2026)
Protocol
ActivityPub, with bridging to ATProto (Bluesky)
Stack
Elixir, Phoenix LiveView, PostgreSQL
License
AGPL-3.0
Funding
Commissioned work building features and spaces with partner communities, an NLnet / NGI Zero grant, and community crowdfunding
Founders
Ivan Minutillo, Mayel de Borniol
