Community

Get involved.

However much you've got, there's a way to take part. Come to listen, lend a hand, bring your community, or sustain the care work.

Where we gather

Three rooms, all of them open.

The workshop

Matrix chat

Day-to-day talk: questions, half-formed ideas, what people are working on. The easiest door: just say hello.

Join the chat →
The playground

The campground

Our open test instance. Make an account, break things, tell us what felt wrong. Data may get reset now and then, don't move in.

Sign up on the campground →
The square

The fediverse

Where we post news, share what we're building, and converse in public. Follow, reply, boost.

Follow @Bonfire →

Ways to help

Small things count. Most of Bonfire is small things.

Fix a good first issue

We keep a list of small, well-described tasks specifically for newcomers to the codebase.

Browse good first issues →

Translate a screen

Bonfire so far speaks English, German, and a bit of other languages like Italian, French, Catalan, etc. If yours is missing, you can fix that.

Translate on Transifex →

Report what broke

Something felt wrong, confusing, or inaccessible? That's may be a bug. Tell us, especially the small annoyances.

Open an issue →

Write code

Elixir, Phoenix, LiveView. Set up a local environment from the docs and dig into an extension.

Read the docs → Get the code →

Improve the docs or website

If something confused you, it'll confuse the next person. Writing it down is a real contribution.

Suggest a doc fix →

Propose an idea

A feature, a better flow, a challenge to an assumption we've made. We'd rather be argued with early.

Open a proposal →

Bring your community

Got a community that needs a home?

Real communities with real needs are what move this project. Co-ops, collectives, unions, newsrooms, research groups, care and mutual aid networks... come tell us how you actually work, and we'll shape a space around it together. Everything we build with you goes back into the commons, for whoever needs it next.

Learn more See how others did it →
